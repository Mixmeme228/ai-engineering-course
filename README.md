## Запуск

Нужен Python 3.11. В полном комплекте:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe tests\check_modules.py
```

Не копируйте шаблон поверх уже заполненного `.env`. Ключи в Git не добавляются. Корневой requirements.txt фиксирует общее проверенное окружение; отдельные requirements модулей сохранены из исходного комплекта и могут задавать более старые версии.

На подготовленной машине `.venv` проекта связан с окружением на диске D:. Python 3.11, зависимости и кэш моделей уже установлены. Кэш: `D:\2\codex-course\work\hf-cache`; для его повторного использования задайте `HF_HOME` этим путём. Перенос на D: освободил место на C:.

Для первого задания также подготовлен VS Code в portable-режиме: `D:\2\codex-course\work\vscode\Code.exe`. Установлены официальные Python и Pylance; настройки проекта указывают на `.venv`. Версии записаны в `evidence/workspace_setup.txt`. Portable-режим выбран, чтобы редактор и расширения размещались на свободном диске D:.

## Troubleshooting

| Симптом | Причина и выполненное действие |
|---|---|
| Неверный ключ GigaChat | В контролируемом опыте основной вызов вернул 400; fallback дошёл до HuggingFace. Настоящий ключ восстановлен в памяти процесса, GigaChat снова отвечает |
| HuggingFace 402 | Ключ принят, но баланс $0.00. Пополнение не выполнялось по решению пользователя |
| Невалидная заявка | Парсер возвращает None, обработка очереди продолжается; неизвестный код и недопустимый приоритет не попадают в базу |
| Инъекция m3 | Модель нарушила формат приоритета, но схема отклонила карточку. Один промпт не считается достаточной защитой |
| Ошибка схемы LLM-судьи | Одна повторная просьба исправить формат, затем честный error. В реальном прогоне 3 вопроса вне базы дали невалидное answer_faithfulness |
| corpus_fingerprint не импортируется | В модуль 4 вместе перенесены завершённые corpus_loader, ingestion и vector_store из модуля 3 |
| Нет места на C: | Рабочее окружение и кэш моделей перенесены в D:\2\codex-course\work; пользовательские файлы не удалялись |

Числа LLM-судьи и проверки по строковой разметке различаются. Ни одна из этих метрик не доказывает безопасность промышленного применения. Учебные SDK-примеры сохраняют настройку TLS из комплекта курса; для рабочего развёртывания требуется корректная цепочка доверенных сертификатов.

## Воспроизведение

Нужен Python 3.11. Из корня проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Если `.env` уже заполнен, не копируйте шаблон поверх него. Значения ключей вводятся только локально. Не добавляйте `.env` в Git.

`requirements.txt` в корне фиксирует фактически установленное общее окружение. Файлы requirements отдельных модулей сохранены из комплекта курса и могут задавать более старые версии. Для общего проекта используйте корневой файл.

На этой машине Python 3.11 и рабочее окружение уже подготовлены в `work` папки чата. Кэш моделей перенесён в `D:\2\codex-course\work\hf-cache`, поскольку на C: закончилось место. Для повторного использования кэша задайте `HF_HOME` этим путём. Новое окружение и большие модели лучше размещать на диске с достаточным свободным местом.

Проверки без API:

```powershell
.venv\Scripts\python.exe tests\check_modules.py
.venv\Scripts\python.exe module_05\rag_lcel.py --stats
.venv\Scripts\python.exe module_05\multi_chain.py --dry
.venv\Scripts\python.exe module_03\embeddings_demo.py
.venv\Scripts\python.exe module_03\ingestion.py --embedded
.venv\Scripts\python.exe module_03\measure_retrieval.py
```

Первая загрузка эмбеддингов скачивает две локальные модели. Встроенный Qdrant предусмотрен курсом как вариант без Docker. Это не серверный dashboard; проверки payload и источников выполнены программно.

## Troubleshooting

| Что видно | Причина | Что сделано / что проверить |
|---|---|---|
| GIGACHAT_CREDENTIALS не найден | Ключ ещё не настроен | Создан локальный .env; заполнить Authorization key, а не временный Access token |
| HF_API_KEY не найден | Нет токена резервного провайдера | Заполнить fine-grained токен с правом Inference Providers |
| 401 GigaChat | Неверные credentials | Переключение на резерв реализовано; настоящее подтверждение требует двух ключей |
| 403 HuggingFace | Нет разрешения, доступа к модели или доступного баланса | Проверить право токена и доступность модели, не перебирать неверные ключи |
| Недостаточно места на C: | Большие локальные зависимости и модели | Собственный кэш моделей перемещён на D:; пользовательские файлы не удалялись |
| `corpus_fingerprint` не импортируется в модуле 4 | Версии вспомогательных файлов комплектов различаются | Вместе перенесены завершённые corpus_loader, ingestion и vector_store из модуля 3 |
| Порог пропускает чужой вопрос | Семантическое сходство не гарантирует наличие ответа | Сохранён замер 0.739 против 0.643; дополнительно нужны контекст, отказ и проверка ответа |

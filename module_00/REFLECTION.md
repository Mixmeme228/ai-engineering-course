# Занятие 1 — рабочая среда и первый вызов

Настроены Python 3.11 и виртуальное окружение, Git-репозиторий, .gitignore, загрузка .env и зависимости. Файл с ключами исключён из Git и передаваемого архива. Корневой .venv использует подготовленное окружение на диске D:.

Подготовлен официальный VS Code в portable-режиме на диске D:, установлены ms-python.python и ms-python.vscode-pylance. Настройки .vscode/settings.json выбирают Python из .venv проекта; фактическая версия интерпретатора 3.11.16. Версии инструментов сохранены в evidence/workspace_setup.txt.

Настоящие вызовы GigaChat выполнены. В финальном прогоне ответ занял 97 токенов и 0.69 с. В более раннем прогоне: 90 токенов и 0.64 с. Это разные ответы, а не усреднение.

В финальном ответе модель ошибочно расшифровала RAG как Research Abstract Graph. Правильная расшифровка — Retrieval-Augmented Generation. Ошибка сохранена в исходном логе; успешный HTTP-вызов не означает правильный ответ модели. Ранний ответ содержал правильную расшифровку, что дополнительно показывает нестабильность содержания.

Токен HuggingFace создан с единственным правом Inference Providers и сохранён локально. Реальный запрос вернул 402 Payment Required. В кабинете баланс $0.00, минимальное пополнение $5. Пользователь выбрал отметить блокировку без пополнения. Поэтому сравнение двух успешных провайдеров не завершено; данные HuggingFace о токенах и latency не выдуманы.

Логи: evidence/hello_llm.txt и evidence/huggingface_probe.json.

# Внутренний регламент предприятия «ПромТех»:  
**«Регламент реагирования на инциденты на технологических установках»**

## Шапка документа

```
# Название документа: Регламент реагирования на технологические инциденты
# Номер документа: РГЛ-РИ-007
# Версия: 3.1
# Утверждён: Директором по производству (ФИО вымышлено), дата утверждения: 01.09.2023 г.
# Вступление в силу: 01.10.2023 г.
# Область действия: Все производственные объекты предприятия ПромТех
# Периодичность пересмотра: раз в три года
```

## Содержание

### 1. Общие положения

1. Целью данного регламента является обеспечение своевременного выявления, документирования и устранения технологических инцидентов на производственных объектах предприятия.
   
   **Проверяемые факты:**
   - Инцидент классифицируется согласно приказу № ПТ-01 от 15.08.2022 г., приложение А.
   - Ответственным лицом за регистрацию инцидента является инженер смены по эксплуатации установки.

### 2. Порядок действий персонала при обнаружении технологического инцидента

2.1. При выявлении инцидента оператор обязан немедленно остановить установку и доложить ответственному лицу.

   **Проверяемые факты:**
   - Оператор обязан зафиксировать время обнаружения инцидента и передать данные в журнал регистрации инцидентов формы РГЛ-Ф-01.
   - Пороговое значение температуры аварийной остановки составляет +120 °C.

2.2. Начальник смены принимает решение о дальнейших действиях после получения доклада оператора.

   **Проверяемые факты:**
   - Решение начальника смены фиксируется в журнале оперативных распоряжений формы РГЛ-Ф-02.
   - Срок принятия решения начальником смены — до 15 минут с момента поступления доклада.

### 3. Планирование мероприятий по устранению последствий инцидента

3.1. После принятия решения о проведении ремонтных работ составляется план мероприятий по ликвидации последствий инцидента.

   **Проверяемые факты:**
   - План мероприятий утверждается главным инженером предприятия не позднее 2 рабочих дней с момента инцидента.
   - Работы проводятся силами специализированной ремонтной бригады, назначенной приказом руководителя производства.

3.2. Для проведения ремонтных работ используется оборудование и материалы, указанные в плане мероприятий.

   **Проверяемые факты:**
   - Ремонтная бригада обязана использовать средства индивидуальной защиты согласно инструкции ИОТ-03-ПРОМТЕХ-2023.
   - Запрещается проведение ремонтных работ при температуре окружающей среды ниже +5 °C без согласования с руководством цеха.

### 4. Документация и отчетность

4.1. По завершении всех мероприятий по устранению последствий инцидента составляется акт расследования инцидента формы РГЛ-Ф-03.

   **Проверяемые факты:**
   - Акт расследования заполняется комиссией, назначаемой руководителем цеха.
   - Форма акта должна включать описание инцидента, причины возникновения, меры предотвращения повторения и подписи членов комиссии.

4.2. Руководитель цеха направляет копию акта расследования инцидента руководителю службы охраны труда не позднее 3 рабочих дней с даты завершения инцидента.

   **Проверяемые факты:**
   - Копия акта направляется по электронной почте с использованием корпоративной системы электронного документооборота.
   - Формат отчёта — электронный файл формата PDF.

### 5. Исключения и особые случаи

5.1. Если инцидент произошел на оборудовании, не входящем в перечень технологического оборудования предприятия, требования данного регламента не распространяются.

   **Проверяемые факты:**  
   - Требования к работе на нестандартном оборудовании определяются отдельным регламентом РГЛ-ХХ-001.

5.2. В случае отсутствия технической документации на установленное оборудование решение о дальнейших действиях принимается инженером по эксплуатации индивидуально.

   **Проверяемые факты:**  
   - Инженер по эксплуатации самостоятельно определяет необходимость остановки установки и порядок дальнейших действий.
